# Prepared API dev smoke harness

Session-local preparation, not runtime qualification. Root owns any deployment, execution, integration, and cleanup. This first-party work is not independent runtime attestation. No Docker, network authentication, deployed runtime, or publication was run during preparation.

This copy preserves the reviewed source harness guards, identity bindings, wrong-image and nonempty falsifiers, per-container and in-container publication attempt markers, single attempt, restricted diagnostics, and cleanup ownership. `orchestrate.py` stages the unchanged copied synthetic `seed.py` and the new `http_verify.py`. It captures all schema objects and rows before and after verification, including on verifier failure; a difference fails the run. On any failure preserve the owned resources and diagnostics; do not retry publication. Guard and publisher must be reviewed against the actual separately authorized train before any invocation.

The verifier authenticates the example local admin, compares the complete attention feed ID set to the published snapshot, then requests each item through its own kind's source-record endpoint with the entire opaque ID percent-encoded. It compares the exact public-model rows, with duplicate multiplicity, to parameter-bound SQL over the published source relation. It checks exact `{item_id, rows}` shape, all four kinds, provably absent keys returning 404 per kind, and a fresh unauthenticated request returning 401. The runtime evidence reports slash and multi-row groups; these are observations, not extra mandatory conditions. The original direct-service `FailClosedWarehouse` check remains a distinct source proof. This harness does not establish built-HTTP no-fallback, 403 source permissions, attention-only behavior, 503 behavior, or out-of-first-page coverage. It does not induce a deployed availability failure.

These are historical observations, not an assertion about the new train. No seed enrichment was needed; actual future counts are reported in verification output.
